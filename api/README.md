# @carbonveritas/api

NestJS backend for the CarbonVeritas protocol. Provides REST endpoints for credit registry, marketplace, retirement, certificates, webhooks, and verifier management.

## Setup

```bash
npm install
npx prisma migrate dev
npm run dev
```

## Endpoints

See OpenAPI docs at `http://localhost:3000/docs` after starting.

## Testing

```bash
npm run test        # unit tests
npm run test:e2e    # e2e tests
```
